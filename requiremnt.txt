App NAme:- IconLab

You are an expert frontend engineer and UI/UX designer.

Build a production-ready web application called:

# IconLab

Tagline:
"Discover. Customize. Download."

The application should be a Flaticon-style icon discovery and customization platform, but with its own branding and UI.

IMPORTANT:
- This is a FRONTEND-ONLY application.
- There is NO backend.
- The application will be deployed directly to NETLIFY.
- Do not create Node/Express/NestJS backend APIs.
- Do not create authentication.
- Do not create a database.
- All icon data should come from the public Iconify API.
- All customization and file generation must happen in the browser.
- Do not use fake/mock icons when the real Iconify API can provide the data.

Use the attached Flaticon screenshots as the visual reference for layout, spacing, information hierarchy, search experience, filters, icon grid, and overall professional feel.

DO NOT copy Flaticon branding, logo, exact colors, or proprietary UI.
Create an original product called IconLab.

ICON SOURCE
==================================================

Use Iconify as the primary icon provider.

Use the Iconify public API for:

- searching icons
- retrieving icon metadata
- retrieving SVG data
- browsing icon collections
- retrieving collection information

Do not hardcode thousands of icons.

The application should dynamically fetch icons from Iconify.

Create a small service layer:

src/
  services/
    iconifyService.ts

Keep all Iconify API calls inside this service.

Do not scatter fetch() calls throughout components.
